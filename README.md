# 授课时长核对 (course-video-audit)

[WorkBuddy](https://www.workbuddy.cn) Skill：给一份"研究所授课汇总"Excel + 讲师照片，全自动核验**视频里是不是本人授课、实际授课时长、授课费算术**，最后产出 HTML 审计报告。全程不停、缺料主动问。

## 它解决什么问题

企业培训费用结算的典型痛点：讲师按申报课时结算授课费，但培训方无法逐条核实——

- 视频回放里到底是不是申报的讲师本人？（冒名/挂名风险）
- 申报课时与视频实际时长是否相符？
- 授课费 = 课时 × 课时费率 的算术是否正确？
- 表内"本期授课费汇总"和逐行明细能否勾稽对上？

本 skill 把这套人工审计流程全自动化。

## 工作流程

```
Excel + 讲师照片(文件名=讲师名)
        │
        ▼
① 解析 Excel（多 sheet，每讲师一页；表头关键字定位，兼容"课时（按分钟折算）"等变体；
   解析"授课时间段"分钟区间，用于切片精确定位）
        │
        ▼
② 登录态自动恢复（CDP 接管已登录浏览器 → 拉起审计 profile → 仍被登录墙拦截才请用户登录一次）
        │
        ▼
③ 批量核验（并发=2 防平台风控；浏览器取流 → 在线探测视频时长，不下载全片；
   SQLite 断点续跑，失败自动重试，时长探测失败永不标 done）
        │
        ▼
④ 抽帧 + 人脸比对（画中画区域裁剪 → 拼图 → 多模态视觉比对底库照片；
   切片型课程在"申报区间内"额外抽帧，直接验证申报时段内是否本人）
        │
        ▼
⑤ 费用勾稽 + HTML 报告（费率表逐条校验、汇总金额勾稽、异常分级汇总）
```

## 能查出的问题（实战验证）

- **疑似挂名申报**：申报区间内是其他讲师出镜，全片密集抽帧确认本人全程未出镜
- **申报区间填错**：本人确实授课，但填的时间段错位
- **时长不足**：视频实测短于申报课时
- **汇总金额不符**：表内汇总 ≠ 逐行明细之和
- **费率口径存疑**：非工作时间费率、线上线下费率混用

## 目录结构

```

│   └── make_montage.py       # 抽帧拼图（画中画/全帧两种模式）
└── references/
    ├── pitfalls.md           # 浏览器/流媒体/ffmpeg/SQLite 踩坑手册
    ├── checks.md             # 核验口径（专场 vs 切片、费率表、人脸判定三档）
    └── report_spec.md        # 报告结构与交付纪律
```

## 使用（WorkBuddy 内）

把 Excel 和讲师照片（照片文件名 = 讲师名，如 `张三.jpg`）发给 WorkBuddy，说一句"核验授课"即可触发。依赖：Chrome、ffmpeg（可用 imageio-ffmpeg 内置版）、Node + playwright-core。

## 免责与边界

- 人脸比对为多模态视觉比对（姓名条 OCR 仅作旁证），如需司法级结论建议接入 InsightFace/ArcFace 向量比对。
- 无直连视频流的平台（如 Wind 节目）自动归入"待人工核验"清单，不阻塞其余条目。
- 请仅对获得授权的内部培训视频使用本工具。
